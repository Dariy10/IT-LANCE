# Web Project
Веб-проект, группа СИ-35.

Проект представляет собой простой персональный веб-сайт для публикации заметок и статей. Пользователи смогут просматривать страницы, изучать учебные материалы и взаимодействовать с контентом.

### Стек технологий
* HTML, CSS, JavaScript, PHP, MySQL.
