# IT-LANCE
Веб-проект, группа СИ-35.

IT-LANCE — сайт услуг для компании/команды, которая оказывает цифровые и IT-услуги. Главная страница помогает потенциальному клиенту быстро понять специализацию, изучить перечень услуг и кейсы, оценить компетенции и оставить заявку на сотрудничество.

### Стек технологий
* HTML, CSS, JavaScript, PHP, MySQL.

### Запуск
1. Клонировать репозиторий:
git clone https://github.com/Dariy10/web-project.git
2. Открыть файл `index.html` в браузере (желательно в Chrome/Firefox).
