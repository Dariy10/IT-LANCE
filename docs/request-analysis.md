# Анализ HTTP-запроса

### Основные параметры запроса
* **URL:** `https://jsonplaceholder.typicode.com/posts/1`
* **HTTP Method:** `GET`
* **Status Code:** `200 OK`
* **Content-Type:** `application/json; charset=utf-8`

### Заголовки (Headers)

#### Request Headers (Заголовки запроса)
* `Accept: application/json` — указывает формат данных, который клиент ожидает получить в ответе.
* `User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36` — сообщает серверу сведения об операционной системе и браузере.
* `Host: jsonplaceholder.typicode.com` — целевой домен сервера.

#### Response Headers (Заголовки ответа)
* `Content-Type: application/json; charset=utf-8` — сообщает тип возвращаемых данных (JSON) и кодировку.
* `Cache-Control: max-age=43200` — директива кэширования ответа.
* `Server: cloudflare` — веб-сервер, отдавший ответ.

### Что произошло между браузером и сервером
1. **Запрос:** Браузер сформировал HTTP-запрос методом `GET` к ресурсу `/posts/1` и передал заголовки с описанием ожидаемого типа контента.
2. **Обработка сервером:** Веб-сервер принял запрос, нашел нужный объект, упаковал данные в формат JSON и сформировал ответ со статусом `200 OK`.
3. **Ответ:** Сервер передал клиенту заголовки и тело ответа. Браузер прочитал полученный JSON и отобразил данные.
