# Project Brief — IT-LANCE

## Название и тип продукта
IT-LANCE — сайт услуг компании, которая оказывает цифровые и IT-услуги.

## Проблема
Потенциальному клиенту нужно быстро понять перечень услуг, компетенции исполнителя/команды и способ связаться.

## Целевой пользователь
Клиенты, которые ищут цифровые/IT-услуги и выбирают подрядчика.

## Основной пользовательский сценарий
1. Пользователь открывает главную страницу IT-LANCE.
2. Знакомится с оффером «IT-аутсорсинг» и списком услуг.
3. Смотрит блок «Для кого» — определяет, подходит ли сервис его типу организации.
4. Изучает преимущества и оценивает компетенции.
5. Оставляет заявку через форму (бесплатный аудит или «Решим вашу IT-задачу»).

## Цель страницы
Представить услуги и довести пользователя до контакта или заявки.

## Ограничения текущей итерации
Реализация только структур и использование только HTML
